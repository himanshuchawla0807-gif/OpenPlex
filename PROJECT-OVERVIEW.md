# Project overview

OpenPlex is a local-first Mac office for AI coworkers. The React interface manages projects, rooms, employee profiles, conversations and workspaces. The Swift wrapper serves the bundled interface and connects it to local coding harnesses through native process and PTY adapters.

See [README.md](README.md) for current functionality, [CONTRIBUTING.md](CONTRIBUTING.md) for source orientation, and [the verification record](docs/release-verification.md) for tested boundaries. Documents describing design experiments or prototypes are historical implementation notes; they do not expand the supported release capabilities.
