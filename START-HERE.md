# Start here

OpenPlex runs as a macOS app and as a browser preview. Choose the path that matches what you want to do.

| Goal | Start with |
| --- | --- |
| Install the Apple Silicon beta | [Download and signing notes](docs/macos-download.md) |
| Build the app and connect an installed agent | [Mac build and first office](docs/getting-started.md#build-the-mac-app) |
| Work on the interface in a browser | [Browser preview](CONTRIBUTING.md#browser-preview) |
| Find the checks for your change | [Contributor verification](CONTRIBUTING.md#before-opening-a-pull-request) |

See the [product tour](README.md), [privacy guide](docs/privacy.md), and [release verification record](docs/release-verification.md) for features, data handling, and beta limitations.
