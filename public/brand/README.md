# OpenPlex identity

Original logo generated for OpenPlex with the built-in OpenAI image-generation tool, 23 October 2026. The mark combines an open workspace with an O/P architectural silhouette in warm plum, ivory and terracotta. The master PNG retains alpha transparency. Smaller favicons and macOS ICNS representations are deterministic size conversions of the same master.

Prompt: “Single centered OpenPlex mark on transparent background. Compact isometric open courtyard / interconnected workspace emblem; an open O and subtle P in negative space. Warm plum, ivory and a muted terracotta accent; tactile dimensional shading, strong silhouette, no extra words, flowers or mockup.”
