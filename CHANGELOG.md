# Changelog

## 0.1.0 source beta — 23 October 2026

- Twelve room types and forty illustrated coworkers, with project-scoped hiring.
- Employee profiles, conversational setup, instructions, skills and explicit MCP configuration.
- Native chat and terminal sessions, resizable team spaces, fresh chats and local task scheduling.
- Shared room conversations and independent Office Communicate status reports.
- Light, dark and system appearance; generated OpenPlex branding and redistributable fonts.
- Loopback, native bridge, managed-file and reporting isolation checks, with documented security and privacy limits.
- Source-first Mac setup instructions, product screenshots and CI checks.

This initial public import groups existing implementation into focused commits. It does not represent thirty separate days of development. Developer ID signing, notarization and broader clean-machine provider validation remain release gates.

- Long work sessions, independent gestures, furniture-aware routes, conversations and small briefings.

Live browser automation remains unverified due to the available browser tool's
access-policy failure. Mathematical interaction checks and actual Canvas renders

are not implemented; characters work within their assigned environments.
